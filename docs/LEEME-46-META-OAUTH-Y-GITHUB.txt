QUÉ SE ARREGLA
  1) "Conectar con Facebook" terminaba en
     http://localhost:5500/dashboard.html?meta=conectado
     → "No se puede acceder a este sitio · localhost rechazó la conexión".
     Causa: el callback de Meta manda el navegador a una URL local
     (localhost:5500 es el Live Server de VS Code: solo existe en tu PC,
     nunca en el servidor de producción). El login en Facebook SÍ terminó
     bien; lo que falla es solo el retorno.
  2) GitHub desaparece del panel de Salud (no lo usan).

ARCHIVOS A SUBIR (3) — todos a la carpeta src/ del backend
  NUEVO   src/oauth-redirect-fix.js   ← el que corrige el retorno localhost
  CAMBIA  src/salud-admin.js          ← v1.2: GitHub fuera + token de Meta desde la BD
  CAMBIA  src/app.js                  ← v7 : activa la corrección (require + middleware)

PASOS DE DESPLIEGUE
  1) Sube los 3 archivos. oauth-redirect-fix.js debe quedar JUNTO a app.js.
  2) (Opcional pero recomendado) En el .env del servidor añade:
         BASE_URL=https://somosvivemas.com
     Si no existe, se usa https://somosvivemas.com por defecto. Si algún día
     cambias de dominio, solo actualizas esa variable.
  3) Reinicia el servicio:  pm2 restart vivemas   (o el nombre de tu proceso)
  4) Verifica: al arrancar debe salir en el log:
         [oauth-fix] Retornos a localhost se corregirán hacia: https://somosvivemas.com

QUÉ ESPERAR AHORA
  - Al conectar Facebook, el navegador aterriza en
        https://somosvivemas.com/dashboard.html?meta=conectado#_=_
    El "#_=_" lo añade SIEMPRE Facebook; es inofensivo, ignóralo.
  - En el log de PM2 verás UNA línea (solo cuando pase):
        [oauth-fix] Retorno a localhost corregido en GET /api/auth/meta/... :
        http://localhost:5500/... → https://somosvivemas.com/...
  - La tarjeta de GitHub ya no aparece en "Salud del sistema" (quedan 5:
    Node, MongoDB, Cloudinary, Stripe, Meta).
  - La tarjeta de Meta debería pasar a VERDE si el token quedó guardado en
    la base de datos al conectar: el motor de salud ahora lo busca en la BD
    (además del .env). Si el token del .env está vencido, prueba el de la BD
    como respaldo. Puede tardar hasta 30 s (caché) en refrescar.
